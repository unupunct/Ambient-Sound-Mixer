# Changelog

## 1.0.0

First release.

- Five scenarios (Ocean, Forest, Waterfall, Rain, Storm), each a set of independently controllable, procedurally generated layers.
- Real-time mixer with per-channel volume, mute and enable, smoothed gain, master volume, soft limiter and clipping indicator.
- White, pink and brown noise generator; binaural beat generator with Delta to Gamma presets.
- Import WAV, MP3, FLAC and other files as looping channels; drag and drop; rename; missing-file handling.
- Presets (save, load, rename, duplicate, delete, restore defaults) and last-session restore.
- Sleep timer with optional fade-out, scenario crossfade, fade in/out.
- Audio device selection, default-device-change and device-failure recovery.
- Dark and light themes, compact mode, always-on-top, system tray.
- Self-contained x64 build, Inno Setup installer, portable ZIP, SHA-256 checksums.
