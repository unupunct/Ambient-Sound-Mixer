## Audio assets

**No third-party audio recordings are bundled.** Every scenario sound (ocean, forest, waterfall, rain, storm),
white/pink/brown noise and binaural tones is generated in real time by the application's own synthesis code
(`src/AmbientSoundMixer.Core/Synthesis`). See `docs/ASSET-MANIFEST.md`.

Audio files that you import are yours; the app only reads them and never copies, modifies or deletes them.

## Fonts and icons

The UI uses fonts and icon glyphs that ship with Windows (Segoe UI, Segoe MDL2 Assets, Segoe UI Emoji); none are
redistributed with this project. The application icon is original artwork generated by `scripts/generate-icon.ps1`.
